# Locally hosted interface fonts

Downloaded from the official Google Fonts CSS service, 2026-09-17.
Noto Sans SC and Manrope variable fonts; IBM Plex Mono 400/600.
All are SIL Open Font License 1.1; original licenses accompany these files.
Upstream: https://github.com/google/fonts/tree/main/ofl

Noto Sans SC is subset to 438 CJK/punctuation characters found in the frontend source plus printable ASCII. Other text uses the system CJK fallback. Manrope and IBM Plex Mono include printable ASCII. No external font requests occur at runtime. Font display uses swap.
